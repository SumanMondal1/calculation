# Screen flow

## 1. Login and role selection
- App opens on login screen.
- Admin logs in with secure credentials.
- Delivery partner logs in with mobile number and password.
- Role-based routes redirect to appropriate dashboard.

## 2. Admin flow
1. Dashboard
2. Delivery partner management
3. Agent management
4. Daily hisab review queue
5. Expense approval queue
6. Settlement approval and reopen flow
7. Reports and export

## 3. Delivery partner flow
1. Dashboard
2. Cylinder delivery entry
3. Agent hisab entry
4. Customer payment entry
5. Agent payment entry
6. Expense entry
7. Cash denomination entry
8. Daily settlement summary
9. Submit daily hisab
10. View approval status and history

## 4. Approval workflow
- Delivery partner submits hisab.
- Admin views full report.
- Admin checks cash denominations, online references, and settlement differences.
- Admin approves, rejects, or requests corrections.
- Reopen is restricted to admin only.

## 5. Reporting flow
- Admin selects date range, partner, or agent filters.
- Reports can be printed, exported to Excel, or PDF.
- Historical reports remain available after approval.
